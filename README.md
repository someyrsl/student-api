## StudentAPI

Проект представляет собой backend на FastAPI для управления данными студентов, их оценками и аутентификацией пользователей.
Также данный проект выступает как мой личный проект для практики REST API, реляционных баз данных, ORM и защиты API через JWT.

> Развитие проекта: изначально прямые SQL-запросы через `sqlite3` → переход на SQLAlchemy (ORM) → добавление связанной таблицы оценок (foreign key, один ко многим) → добавление регистрации, логина и защиты эндпоинтов через JWT-токены.

## Стэк

- Python 3
- FastAPI
- SQLAlchemy (ORM)
- SQLite
- bcrypt — хэширование паролей
- python-jose — генерация и проверка JWT-токенов

## Функциональность

1. Создание, получение и удаление студентов
2. Создание, получение и обновление оценок, привязанных к студенту (один студент — много оценок)
3. Регистрация и логин пользователей с безопасным хэшированием паролей
4. Защита операций изменения данных через JWT-токен (создание/обновление/удаление доступны только авторизованным пользователям, просмотр — открыт всем)
5. Валидация данных через Pydantic-модели
6. Обработка ошибок с корректными HTTP-кодами (401, 404, 409)

## Структура данных

```
students                    grades                       users
┌────┬─────────┬─────┐      ┌────┬────────────┬───────┐  ┌────┬──────────┬─────────────────┐
│ id │ name    │ age │      │ id │ student_id │ score │  │ id │ username │ hashed_password │
└────┴─────────┴─────┘      └────┴────────────┴───────┘  └────┴──────────┴─────────────────┘
                                     ↑
                             ссылается на students.id
```

## Структура проекта

```
main.py       — точка входа и подключение роутеров
models.py      — модели данных: Pydantic (Student, Grade, Users) + SQLAlchemy (StudentDB, GradeDB, UsersDB)
database.py     — подключение к базе через SQLAlchemy (engine, сессии)
auth.py          — хэширование паролей, создание и проверка JWT-токенов
students.py       — эндпоинты для работы со студентами и их оценками
users.py            — эндпоинты регистрации и логина
```

## Запуск

```bash
pip install fastapi uvicorn sqlalchemy bcrypt "python-jose[cryptography]"
uvicorn main:app --reload
```

После запуска документация API доступна по адресу `http://127.0.0.1:8000/docs`

## Аутентификация

1. Зарегистрируйтесь через `POST /register` (username, password)
2. Войдите через `POST /login` — в ответ придёт `access_token`
3. Для защищённых эндпоинтов добавьте заголовок:
```
Authorization: Bearer <access_token>
```

## Эндпоинты

| Метод | Путь | Описание | Требует токен |
|---|---|---|---|
| POST | `/register` | Зарегистрировать пользователя | Нет |
| POST | `/login` | Войти, получить токен | Нет |
| POST | `/students/{student_id}` | Создать студента | Да |
| GET | `/students/{student_id}` | Получить студента вместе со всеми его оценками | Нет |
| DELETE | `/students/{student_id}` | Удалить студента | Да |
| POST | `/students/{student_id}/grades` | Добавить оценку студенту | Да |
| GET | `/students/{student_id}/grades` | Получить список оценок студента | Нет |
| PUT | `/students/{student_id}/grades/{grade_id}` | Обновить конкретную оценку | Да |
