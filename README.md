## StudentAPI

Проект представляет собой простой backend на FastAPI для управления данными студентов и их оценками.
Также данный проект выступает как мой личный проект для практики REST API, реляционных баз данных и ORM.

> Изначально проект использовал прямые SQL-запросы через `sqlite3`, позже переписан на SQLAlchemy (ORM). Позже структура была расширена: оценки вынесены в отдельную таблицу, связанную со студентами через foreign key (отношение "один ко многим").

## Стэк

- Python 3
- FastAPI
- SQLAlchemy (ORM)
- SQLite

## Функциональность

1. Создание, получение и удаление студентов
2. Создание, получение и обновление оценок, привязанных к студенту (один студент — много оценок)
3. Валидация данных через Pydantic-модели
4. Обработка ошибок с корректными HTTP-кодами (404, 409)

## Структура данных

```
students                    grades
┌────┬─────────┬─────┐      ┌────┬────────────┬─────────┬───────┐
│ id │ name    │ age │      │ id │ student_id │ subject │ score │
└────┴─────────┴─────┘      └────┴────────────┴─────────┴───────┘
                                     ↑
                             ссылается на students.id
```

## Структура проекта

```
main.py       — точка входа и подключение роутеров
models.py      — модели данных: Pydantic (Student, Grade) + SQLAlchemy (StudentDB, GradeDB)
database.py     — подключение к базе через SQLAlchemy (engine, сессии)
students.py      — эндпоинты для работы со студентами и их оценками
```

## Запуск

```bash
pip install fastapi uvicorn sqlalchemy
uvicorn main:app --reload
```

После запуска документация API доступна по адресу `http://127.0.0.1:8000/docs`

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| POST | `/students/{student_id}` | Создать студента |
| GET | `/students/{student_id}` | Получить студента вместе со всеми его оценками |
| DELETE | `/students/{student_id}` | Удалить студента |
| POST | `/students/{student_id}/grades` | Добавить оценку студенту |
| GET | `/students/{student_id}/grades` | Получить список оценок студента |
| PUT | `/students/{student_id}/grades/{grade_id}` | Обновить конкретную оценку |
